# Frontend Ikarama

Voir le `README.md` à la racine du dépôt (organisation de `src/`, commandes, recettes).

```bash
npm install
npm run dev      # développement, http://localhost:4002
npm run build    # production -> build/
npx vue-tsc --noEmit -p tsconfig.app.json   # vérification des types
```
